## Evidence labels

Keep four things distinct in every study note:

1. **Source** — link, title, author, and the particular chapter/page/diagram.
2. **Observed** — only what is directly visible or stated; record timestamps and unclear parts.
3. **Practice** — the Blender scene and exactly what was reproduced or deliberately varied.
4. **Result** — cage/surface checks, what worked, what failed, and the next unresolved question.

“Read”, “sampled”, “watched to completion”, and “reproduced” are different states. Never turn a transcript or a few screenshots into a claim of full visual analysis. Record limitations beside the claim.

## File hygiene

- Keep one canonical copy of source transcripts and large source captures. Link to them from topical notes instead of copying them into every study folder.
- Store dated progress in one current file per study; move completed history to `archive/records` only when the current index preserves its useful conclusions and links.
- Before removing anything, compare hashes and search for file-path references. Exact duplicate downloads can be removed after their canonical copy is identified. Similar-looking model versions, user edits, originals, and uncertain references are not duplicates.
- Do not delete source material based on age or file name alone. Put uncertain cleanup candidates in an inventory for review.
