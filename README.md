## Reading the evidence

The saved models and current images are checkpoints, not claims of professional quality or complete tutorial fidelity. Historical notes may refer to earlier geometry, canceled exercises or local-only media. Later entries supersede earlier status. Recorded lessons are reusable documentation, not permanent model training. Sampled frames and transcripts are not equivalent to watching every operation.

Match silhouette, cross-section, thickness, seating and actual part connectivity before detailing. Favor useful mostly-quad flow without forcing slivers just to eliminate triangles. Check base meshes, evaluated modifiers and shading; counts alone cannot certify quality.

## Local library versus public repository

This repository uses an explicit file allowlist. It contains authored project checkpoints, source, selected review renders, validation records and written study notes. Original videos, standalone reference downloads, extracted tutorial frames, downloaded article images/transcripts, third-party tool checkouts, runtimes, connection credentials and unrelated personal models remain local. Some historical note links therefore refer to local-only evidence. Saved Blender projects may contain packed reference imagery already used by the working scene; this repository does not grant rights to third-party source material.

One current blend is retained per active project/exercise. No model decimation or topology simplification was performed during publication. Sources are procedural checkpoint builders, not production-ready standalone tools: inspect their prerequisites and output paths before running them. Exercise scripts can replace geometry; review scripts belong in a separate Blender process. Preserve the user's working scene and settings.
